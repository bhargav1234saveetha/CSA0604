DAA ASSIGNMENT 4B - IMPLEMENTATION FOLDER
=========================================

This folder contains Python implementations for all six tasks in 4B.

FILES
-----
main.py             Runs all six tasks.
word_wrap.py        Task 1: DP Word Wrap, widths 16/20/24 and boundary tests.
knapsack.py         Task 2: Fractional greedy and 0/1 Knapsack DP.
routing.py          Task 3: Dijkstra, Bellman-Ford, Floyd-Warshall, Warshall.
assembly_line.py    Task 4: Two-line assembly scheduling and changed-input tests.
mst.py              Task 5: Kruskal, Prim and Boruvka MST algorithms.
tsp.py              Task 6: Held-Karp TSP DP and exhaustive validation.

RUN
---
1. Extract this ZIP file.
2. Open the folder in VS Code.
3. Open Terminal > New Terminal.
4. Run: python main.py

No external Python packages are required.

SUBMISSION
----------
