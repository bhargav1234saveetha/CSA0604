DAA ASSIGNMENT 4 - PART I IMPLEMENTATION
========================================

This folder contains Python implementations for all six tasks in a1.pdf.

FILES
-----
main.py                 Runs all six task demonstrations.
fractional_knapsack.py  Task 1: Fractional Knapsack greedy algorithm.
job_sequencing.py       Task 2: Job sequencing with deadlines and profit.
knapsack01.py           Task 3: 0/1 Knapsack using dynamic programming.
word_break.py           Task 4: Correct Word Break DP with reconstruction.
shortest_paths.py       Task 5: Dijkstra, Bellman-Ford and Floyd-Warshall.
weighted_interval.py    Task 6: Energy-aware weighted interval scheduling.

HOW TO RUN
----------
1. Extract the ZIP file.
2. Open the extracted folder in VS Code.
3. Open Terminal > New Terminal.
4. Run:

       python main.py

No external Python packages are required.
